```dafny
function num_bits(x: nat): nat
```

|x|binary representation|num_bits(x)|num_bits(x) - 1 > 0?|
|---|---|---|---|
|0|0|1|no|
|1|1|1|no|
|2|10|2|yes|
|3|11|2|yes|
|4|100|3|yes|
|19|10011|5|yes|

General rule:

- for x = 0 and x = 1, we have x / 2 == 0, so the function returns 1;
- for x >= 2, it returns 1 + num_bits(x/2), and since num_bits is always >= 1, the result is >= 2.

Therefore, num_bits(x) - 1 > 0 is equivalent to x >= 2.
